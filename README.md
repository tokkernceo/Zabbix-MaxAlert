# Интеграция Zabbix с мессенджером MAX

Данный репозиторий содержит скрипт для Zabbix Media Type (Способа оповещения), который позволяет отправлять уведомления из Zabbix в мессенджер MAX через официальный Webhook API.

Настройка этого способа оповещения **полностью аналогична настройке отправки уведомлений в Telegram**. Это просто еще один **Способ оповещения (Media type)** в Zabbix, который использует Webhook для отправки POST-запросов к API мессенджера MAX. Если вы уже настраивали Telegram в Zabbix, то этот процесс покажется вам абсолютно знакомым.

## Требования
- Zabbix 5.0 или выше (используется Webhook).
- Токен бота MAX.
- ID чата (или пользователя) в MAX (`chat_id`).

## Настройка способа оповещения в Zabbix

1. Перейдите в **Оповещения (Alerts)** -> **Способы оповещений (Media types)** и нажмите **Создать способ оповещения (Create media type)**.
2. Заполните основные поля:
   - **Имя (Name)**: `MAX` (или любое другое на ваше усмотрение)
   - **Тип (Type)**: `Webhook`
3. Добавьте следующие **Параметры (Parameters)**:
   - `Message` = `{ALERT.MESSAGE}` (Текст сообщения)
   - `ParseMode` = `markdown` (или `html`, или оставьте пустым)
   - `Subject` = `{ALERT.SUBJECT}` (Тема сообщения)
   - `To` = `{ALERT.SENDTO}` (ID чата, куда отправлять. В настройках пользователя укажите ваш `chat_id`)
   - `Token` = `ваш_токен_бота` (В настройках пользователя или прямо здесь укажите токен)
4. В поле **Скрипт (Script)** вставьте код из файла `max_webhook.js`, который находится в этом репозитории.
5. Установите **Время ожидания (Timeout)**: `30s`.
6. Убедитесь, что стоит галочка **Активировано (Enabled)** и нажмите **Обновить (Update)**.

## Настройка получателя (Пользователя)
Аналогично Telegram, вам нужно привязать этот способ оповещения к пользователю:
1. Перейдите в **Администрирование (Administration)** -> **Пользователи (Users)**.
2. Выберите пользователя, который будет получать уведомления.
3. Перейдите во вкладку **Способы оповещений (Media)**.
4. Нажмите **Добавить (Add)**.
5. Выберите **Тип (Type)**: `MAX`.
6. В поле **Отправлять на (Send to)** укажите ваш `chat_id` (например, `123456789`).
7. В поле **Token** укажите ваш токен бота.
8. Нажмите **Добавить (Add)** и **Обновить (Update)**.

## Настройка триггеров (Actions)
Чтобы уведомления уходили, настройте действие в **Оповещения (Alerts)** -> **Действия (Actions)** -> **Действия триггеров (Trigger actions)**.
Убедитесь, что в операциях (Operations) выбран ваш способ оповещения `MAX`, а макросы `{ALERT.SUBJECT}` и `{ALERT.MESSAGE}` передаются в параметры скрипта.

## Безопасность
- Никогда не храните реальные токены в открытом виде в публичных репозиториях.
- Если токен скомпрометирован, немедленно перевыпустите его в панели управления ботом MAX.
